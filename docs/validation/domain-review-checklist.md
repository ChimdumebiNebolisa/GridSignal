### Review questions

1. Does structural need reflect planning priorities you would use in resilience conversations?
2. Is solar feasibility clearly separated from need?
3. Are data gaps and missing components visible enough?
4. Is statewide ERCO load context useful without implying county grid reliability?
5. Are labels ("Elevated", "Moderate") appropriately cautious?
